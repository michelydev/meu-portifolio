# Michelely Archetti — Portfólio

Portfólio pessoal desenvolvido para apresentação profissional como desenvolvedora Front-end, reunindo projetos, habilidades e evolução contínua na área de tecnologia.

---

## 📌 Visão Geral

Este projeto tem como objetivo central apresentar minha trajetória como desenvolvedora, destacando competências técnicas, projetos práticos e foco em criação de interfaces modernas e responsivas.

O portfólio é constantemente atualizado conforme avanço nos estudos e novas experiências.

---

## 🧠 Stack

- HTML5 (semântico e acessível)
- CSS3 (Flexbox, Grid, responsividade)
- JavaScript (interatividade e lógica de UI)
- Git & GitHub (versionamento)
- Deploy via GitHub Pages

---

## 🎨 UI / UX

- Layout minimalista e focado em legibilidade
- Uso de gradientes suaves e identidade visual moderna
- Componentes com micro-interações (hover e transições)
- Estrutura responsiva (mobile-first)
- Organização em seções claras e objetivas
